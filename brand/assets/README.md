# Somebody brand assets

Browser-ready WebP assets derived from the approved Somebody mascot concept.

## Core assets

- `somebody-avatar.webp` — app/avatar mark
- `somebody-hero-wide.webp` — lightweight wide hero/title-card reference

## Mascot states

- `mascot/somebody-neutral.webp`
- `mascot/somebody-working.webp`
- `mascot/somebody-searching.webp`
- `mascot/somebody-following-up.webp`
- `mascot/somebody-needs-approval.webp`
- `mascot/somebody-waiting.webp`
- `mascot/somebody-done-verified.webp`

Canonical product line: **Somebody has to do it. Now Somebody can.**

Character and usage rules live in `../SOMEBODY_BRAND.md`.

The full-resolution generation boards and lossless working assets are retained in the separately archived `somebody-assets-v1.zip`; they are intentionally not committed here to keep the hackathon repository lightweight.
